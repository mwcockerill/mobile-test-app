# my-tests

This folder is yours. Write your Maestro flows here as you work through the [lessons](../lessons/00-setup.md), for example `my-tests/01-launch.yaml`.

`my-first-test.yaml` is the smoke test from Lesson 0. It checks that your setup works.

Run one flow:

```bash
maestro test my-tests/01-launch.yaml
```

Run them all:

```bash
maestro test my-tests/
```

Reference answers are in [`../solutions/`](../solutions). Try each lesson yourself first. You'll learn far more from getting stuck and working it out than from reading an answer.
